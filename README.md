Expense Tracker

A simple Python program for managing personal expenses.

Features

- Add expenses
- View all expenses
- Search expenses by category
- Delete expenses
- Calculate total expenses
- Show expenses by category
- Save expenses in a JSON file
- Validate user input

How to Run

Run the program with:

python main.py

Data

Expenses are stored in:

expenses.json
